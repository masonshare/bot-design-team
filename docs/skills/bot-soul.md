# bot-soul

## What it does

Writes, trims or reviews a bot soul: the standing instructions carried on every turn (identity, voice, scope, gates, skill pointers).

Source: [`packs/starter/pink-pepper-coated-lotus-seeds/skills/bot-soul/SKILL.md`](../../packs/starter/pink-pepper-coated-lotus-seeds/skills/bot-soul/SKILL.md)

## When to reach for it

You want a SOUL.md or system prompt for a persistent assistant, or a soul that is too long or ignored.

## Common questions

**How long should a soul be?** Short. Detail needed only sometimes moves into skills.

**Can it review an existing soul?** Yes, and it can shorten it.

**What about the profile?** Write the profile first with bot-profile.

## It's working if

- The soul names identity, scope, gates and which skills to use.
- Material used only occasionally lives in a skill, not the soul.
- The bot follows the soul in a short test chat.
