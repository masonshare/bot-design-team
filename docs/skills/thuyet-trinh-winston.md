# thuyet-trinh-winston

## What it does

Designs talks that stick with enforceable rules instead of tips, in three modes: DESIGN (a full talk from an idea, transcript, article, notes, or a skill file or prompt), AUDIT (check an existing deck or script and name concrete defects) and PACKAGE (pack one idea with the 5S star: slogan, symbol, salient idea, surprise, story). It outputs an outline, a slide-by-slide plan, speaker notes and a rehearsal checklist. Body in Vietnamese, description bilingual.

Drafting a talk with a language model tends to produce slides that hold everything in the source, with many words, three main points and a closing "thank you". The skill turns public-speaking method into checkable constraints (count the words, pick one idea, repeat it three times). It has two mandatory stopping points, covers online, hybrid and stage settings, and digests a source rather than copying it. Known weak spots from testing: it can leave figures blank and uses internal shorthand rules (R1 to R13, B6) that an outsider will not follow. Reference points: minimum 40 pt type (a forcing rule, not a readability standard); at most 20 to 25 words per slide; repeat the core idea 3 times; wait 3 to 5 seconds after a question; change pace every 5 to 8 minutes; keep about 20 percent for questions and risk; source summary of at most 15 lines. Every number in this skill is a labelled reference point, not a fact about your market or channel; the skill asks for your own figures.

## When to reach for it

Someone asks to prepare a talk, make slides for a meeting, audit a deck, or pack one idea so it is remembered. For a board pitch built from canvases and interviews use `pitch-bod-bos-dt`, which is a real boundary between the two; for negotiating use `elite-negotiator`. Links are soft.

## Common questions

**What is the difference between the three modes?** DESIGN builds a talk, AUDIT finds defects in one you have, PACKAGE condenses one idea into the 5S form.

**Will it write all the slide text?** No. It limits words per slide on purpose and puts the rest in speaker notes.

**Why are some rules numbered like R10?** They are shorthand in the skill's rule list. If a label means nothing to you, ask for it in plain words.

## It's working if

- The talk has one salient idea, repeated three times, with a stated promise at the start and no "thank you" ending.
- Slides respect the word limit and the rules were checked as the draft was produced, not afterwards.
- A rehearsal checklist and a time plan with room for questions are included.
