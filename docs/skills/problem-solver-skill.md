# problem-solver-skill

## What it does

A strategic problem solver for founders and executives: it frames the problem, diagnoses root causes, maps competitive dynamics, compares options against explicit criteria, and turns the pick into an action plan with owners and checkpoints. It always names the framework it used so the reasoning can be checked. Eight steps from framing to action plan; a decision matrix with weighted criteria is built in. Body in English, description bilingual.

Leaders tend to act on the first explanation, or get stuck because the problem is too wide. The skill keeps a fixed order and a fixed output (frame, diagnosis, options and evaluation, recommendation, action plan, assumptions, next step). Roughly a thousand lines of framework reference were folded into one framework-choice table and one problem-brief template. Reference points: at least 3 layers of "why"; 3 to 6 options; 4 to 6 matrix criteria with weights summing to 100; 5 to 10 actions and 2 to 4 checkpoints; for reversible decisions, decide at about 70 percent of the information, adjusted for risk. Every number in this skill is a labelled reference point, not a fact about your market; the skill asks for your own figures.

## When to reach for it

Someone asks why a problem keeps happening, for a root cause, a pre-mortem or an action plan, or is stuck on an operational or organisational problem. Market and competitive strategy choices belong to `business-strategist` when it is installed; for a fixed four-section systems analysis use `system-thinking`. Links are soft.

## Common questions

**How is it different from `system-thinking`?** They overlap on root cause. This one carries on to options, a decision matrix and an owner-assigned action plan; `system-thinking` stops at the structured analysis.

**Does it ask many questions first?** One round, each with a default, and it labels what it assumed.

**Which frameworks does it use?** It picks from its framework table and says which, so you can challenge the choice.

## It's working if

- The output has the fixed sections from frame to next step.
- The root-cause step goes at least 3 layers of "why" deep.
- The action plan names owners and checkpoints, and assumptions are listed.
