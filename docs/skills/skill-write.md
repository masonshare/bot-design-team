# skill-write

## What it does

Writes the description and SKILL.md body of one skill, choosing its size tier and the split between SKILL.md, references and scripts.

Source: [`packs/starter/mango-spring-roll/skills/skill-write/SKILL.md`](../../packs/starter/mango-spring-roll/skills/skill-write/SKILL.md)

## When to reach for it

You decided what the skill does and want SKILL.md drafted, or have a bloated skill to restructure.

## Common questions

**How long should SKILL.md be?** Under 500 lines; move detail to references.

**What makes a good description?** What it does, when to use it, and what it is not for.

**Does it test?** No. Use skill-test.

## It's working if

- The description states job, triggers and exclusions.
- SKILL.md is under 500 lines.
- validate_skill.py passes.
