# copywriter-choi-chu

## What it does

Writes or sharpens Vietnamese copy (tagline, slogan, name, caption, announcement, email, text inside an image) with a six-step process: thinking line, word gathering, word ordering, tone, sentence building, wordplay. A seventh step covers visual direction when the words go with an image: pick a visual twist and image style, and write an image prompt that keeps the exact Vietnamese text with its diacritics. It records its process so the user can learn from it. Body in Vietnamese, description bilingual. Four reference files hold sentence rules, wordplay techniques, visual twists and a quality checklist.

Vietnamese copy often fails because the writer jumps into wordplay before there is an idea, a chosen word set or a tone. The skill forces the order and scales it to the job. The earlier 62-file version was condensed into SKILL.md plus four references: 12 visual twists and 8 style families replace the earlier libraries of 18 and 32, and every example is invented. The owner has read the wordplay examples and approved them; a native speaker's ear is still the best final check, so keep reading them aloud. It reads `brand-profile.md` when there is one and does not require it. Reference points: 3 to 5 keywords in step 3; a word field of 15 to 30 words; at most 1 filler word per 2 sentences; text in an image at most 3 lines of about 6 to 8 words; a 7-question tagline score of 0 to 2 each, 14 at most (under 9 rewrite, 9 to 11 polish, 12 or more protect); consider splitting a sentence beyond about 20 words; deliver 2 to 3 options. Every number is a reference point, not a fact about your market. Known weak spots from testing: in one run it miscounted words (64 instead of 62) and invented shop details, so check counts and facts yourself.

## When to reach for it

Someone asks to write a slogan, play with words, name something, fix a sentence so it reads better, or sends an image and wants a pun that fits it. For persuasive long copy (pages, ads, articles) use `copywriter-skill`; for visuals of a product listing use `ecommerce-image-design`. Links are soft.

## Common questions

**Why does it ask about the idea before the words?** The idea has to exist before wordplay, and wordplay on a weak idea reads as a trick. The first steps settle the idea and the word set.

**Does it write the image too?** Step 7 only writes the direction and an image prompt that preserves the exact Vietnamese text. Generating images, and any cost, is up to you.

**How long do the options run?** It delivers 2 to 3 options, each with its reasoning, so you can choose.

## It's working if

- The thinking line (the idea) is stated before any wordplay is offered.
- Two to three options come with the process recorded, and each tagline is scored on the 7 questions.
- When words go with an image, the image prompt keeps the exact Vietnamese text and diacritics.
