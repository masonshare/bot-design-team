# ecommerce-store-optimization

## What it does

Audits the four pages that matter in an online store (storefront, category, search results, product detail) with concrete checklists, mobile first, plus a quick gate before running ads. It reads the customer's `brand-profile.md` when there is one, and uses placeholders such as [Brand] in example titles.

Shoppers who visit but do not buy are usually facing a page with too few images, too little information or too few reviews. The product page is checked first because the buying decision happens there. It checks structure and does not write ad copy; image sizes and platform rules are flagged to re-check rather than given as hard numbers. Reference points: about 6 to 8 images and one video; about 20 reviews before ads; rating under about 4.5 stars to fix before raising ad spend. Every number in this skill is a labelled reference point, not a fact about your market; the skill asks for your own figures.

Source: [`packs/marketing-ecommerce/skills/ecommerce-store-optimization/SKILL.md`](../../packs/marketing-ecommerce/skills/ecommerce-store-optimization/SKILL.md)

## When to reach for it

An owner asks what a product page is missing, what images are needed, how to fix listing names and titles for search, what sections a description needs (structure only), why visitors do not buy, or asks for a store audit. To write the selling copy itself use a copywriting skill.

## Common questions

**Does it write my product description?** No. It checks the structure and tells you what is missing. Writing the persuasive text is a copywriting job.

**Do I need a brand profile?** Optional. If you have one it follows the voice and names; if not it uses placeholders.

**Why no hard image sizes?** Platforms change them. The skill tells you to check the current rules.

## It's working if

- It audits the product detail page first and in checklist form.
- The output lists what is missing per page, in priority order.
- It ends with the quick gate to pass before running ads.
