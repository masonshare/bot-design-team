# playbook-documentation

## What it does

Turns operating know-how into a playbook a newcomer can follow: a one-page SOP template, five document types, a build-test-maintain checklist, and a launch playbook for repeating a business. By default it saves to Google Docs.

What lives in one person's head cannot be copied. The skill includes a step where two or three people who do not know the task try the playbook, because that is the most reliable test; it suggests a full review each quarter to keep documents alive. The launch playbook is a suggested frame only. Every number in this skill is a labelled reference point, not a fact about your market; the skill asks for your own figures. Notion and other tools appear only as options in a table.

Source: [`packs/marketing-ecommerce/skills/playbook-documentation/SKILL.md`](../../packs/marketing-ecommerce/skills/playbook-documentation/SKILL.md)

## When to reach for it

An owner asks how to write an SOP, how to let someone else run the work, how to document the company, or how to package a process. For deciding what to do rather than documenting it, use a strategy skill.

## Common questions

**Where is the document saved?** Google Docs by default, or the tool the customer already uses.

**What are the five document types?** They are listed in the skill, from one-page SOPs up to the launch playbook.

**How do I know the playbook is good?** Someone new follows it without asking you questions.

## It's working if

- The playbook uses the one-page template with numbered steps.
- A newcomer was asked to follow it and the stuck points were fixed.
- A review date is set for the next quarter.
