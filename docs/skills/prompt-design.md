# prompt-design

## What it does

Writes one new prompt from a brief, using a gold-standard example and a reality check, and points other prompt work to the matching prompt-* skill.

Source: [`packs/starter/pink-pepper-coated-lotus-seeds/skills/prompt-design/SKILL.md`](../../packs/starter/pink-pepper-coated-lotus-seeds/skills/prompt-design/SKILL.md)

## When to reach for it

You want a prompt for a summary, email, analysis, image or code request, or are unsure which prompt skill to use.

## Common questions

**What if I already have a prompt?** Use prompt-review.

**What if the task has several steps?** Use prompt-chain.

**Where are the techniques?** references/techniques.md in the skill.

## It's working if

- The prompt states task, context, format and limits.
- A reality check run gave an output you would accept.
- You know which sibling skill to use next.
