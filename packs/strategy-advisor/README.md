# Pack: strategy-advisor (strategy and CEO-level thinking)

A set of skills for business strategy, problem solving, startup analysis, negotiation and presentations. The skills are written to be neutral, so they run on Claude Code and on Codex.

Needs the Starter pack first (`packs/starter/`): install it before this one.

This pack is created empty in batch 0 and filled in by later batches. Each skill will have a docs page in `docs/skills/`; sources and licences go in `docs/credits.md`. If you need to read a video, also install `youtube-digest` from `packs/marketing-ecommerce/`.

Same rules as the marketing pack: neutral wording (no agent-only tool names, no machine paths, no real company names, no URLs), checked by `scripts/check-skill-neutral.py`; all sample data is FAKE. Skills that need brand facts read the customer's `brand-profile.md` (template: `packs/marketing-ecommerce/brand-profile-template.md`).
