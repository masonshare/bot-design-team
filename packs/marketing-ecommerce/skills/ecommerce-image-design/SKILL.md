# E-commerce image design

Goal: turn a product and a selling message into a clear shot plan and copy-ready prompts that a designer or an image tool can execute without guessing. Accuracy of the brief and of the product comes before creativity.

## Default behaviour (read first)

- The default deliverable is a **prompt package for the owner to review**. No image is generated by default.
- Each image gets one prompt in Vietnamese (the version to review) and one English version (for generators that follow English better).
- Run a generation tool only when BOTH are true: the user has connected one, and the user has approved the cost explicitly for this run (state the tool, the number of images, and the estimated cost if the tool can quote it). Approval for one run does not carry over to the next.
- If either condition is missing, hand over the prompts and say what is needed to generate.
- Never present a draft as generated, approved or final when it is not.

## Customer brand context

If the client keeps a `brand-profile.md` (name, positioning, audience, tone, colours, photo style, products, limits), read it first and do not re-ask what it already answers. Take from it: palette, photo style, forbidden claims or visuals, packaging rules. If there is none, ask the missing brief items once, each question with a default, and offer to save the answers as a brief block.

## When not to use

- Writing the headline, bullets or product description text: use `copywriter-skill` if installed; otherwise draft only the short on-image text here.
- Fixing the whole listing (title, price, reviews, conversion): use `ecommerce-store-optimization` if installed; otherwise limit yourself to the images.
- Promotion mechanics and calendar: use `ecommerce-promotion-design` if installed.
- Video, motion or 3D: out of scope; hand over a still-image plan only.

## Workflow

1. **Brief intake.** Confirm the eight items below. Ask only for what is missing, and wait for blockers (product, platform, message) before writing prompts.
   - Product (name, pack, number of SKUs), category, platform or tool, image type and count, main message, brand rules (logo, colours, fonts, previous visuals), target customer, deadline and number of revisions.
   - Optional: mood, exact on-image copy, reference images, who will do post-production.
   - Template for the normalised brief: `references/brief-and-delivery.md`.
2. **Input check.** Look at what the user supplied: product photos (front, angled, close-up), packaging files, logo, previous campaign images. Low-resolution, cropped or reflective photos make poor references; ask for better ones rather than forcing them. If competitor listings or screenshots are available, note three things: what they all do, what none of them does, and what you will do differently. Browse only if the platform has a search or read-web tool; otherwise ask the user to paste or upload.
3. **Platform spec.** Match ratio, final size, file limit, number of image slots and the mobile safe zone to where the image will be used. Generators follow a ratio better than exact pixels, so generate the nearest ratio, keep key content inside the central 80 percent, then resize and crop to the export size. Seller-centre rules change; ask the user to confirm current limits before final export. Ratio guide (reference points): 1:1 cover and detail images, 4:5 social feed, 9:16 story or vertical ad, 3:2 website hero, very wide (about 8:3) shop banner.
4. **Shot or layout plan.** Give every image a role: hero, key benefit, ingredient or material, usage, lifestyle, comparison or spec, proof, gift or combo. For each, decide the visual mode, angle, composition, mood, props, copy zone and what the viewer should read first. Use the table in the next section.
5. **Prompt writing.** Follow the prompt stack and the rules below. Produce the Vietnamese prompt first, then the English version.
6. **Review.** Run the checklist in `references/brief-and-delivery.md` before delivery. When a generated or supplied image is weak, repair it with the smallest instruction that fixes the named problem, not a full rewrite.
7. **Delivery.** Use the delivery template in the same file: normalised brief, plan table, prompts, checklist result, open questions, status (not generated, or generated with approval).

## Choosing a visual language

Pick one mode per image, then at most two cues each for angle, light and palette. A fuller cue list is in `references/visual-language.md`.

| Mode | Use when | Core instruction |
|---|---|---|
| Studio product | Cover, thumbnail, clean listing | Plain background, sharp label, soft controlled shadow |
| Lifestyle | Usage, emotion, gifting moment | Product integrated in a believable local setting |
| Ingredient flat lay | Food or beverage trust | Overhead view, product central, ingredients around it |
| Macro texture | Quality, freshness, tactile detail | Close-up, shallow depth, appetising surface |
| Gift-set scene | Complete gift solution | Open box, arrangement, ribbon, card, logo zone |
| Infographic | Benefits, specs, comparison | Clear hierarchy, verified short copy only |
| Campaign creative | Sale, season, launch | Strong hero, large clean copy area |
| Landing hero | Wide page header | Product on one side, copy zone on the other |

Quick angle rule: front for label clarity, 45 degrees for the volume of jars and boxes, overhead for flat lays and combos, eye level for human scenes, macro for texture proof.

## Prompt rules

- Stack, in this order: image type and role, subject, setting, composition and camera, light and colour, style, product fidelity, on-image text, ratio and quality, constraints.
- **Product fidelity is the top constraint.** State that the shape, colour, label and packaging of the attached reference must stay exactly as they are. Do not ask a generator to redraw labels, logos, QR codes, certification seals or legal text; keep those as supplied assets placed in editing software. When exact packaging matters, generate the background and mood only and composite the real product.
- Put the exact on-image copy inside the same prompt, in quotation marks, with line breaks, hierarchy, position and contrast. Do not split each image into separate description, copy and negative sections. If there is no copy, say so explicitly ("Nội dung chữ: không có").
- Constraints must not forbid text when copy is requested; write "no extra text beyond the quoted copy, no misspelling, no watermark, no fake label, no duplicate product".
- Do not invent claims, certifications, awards, reviews, prices or origin statements. Use a visible placeholder such as `[CẦN DUYỆT]` until the user supplies them.
- Describe style references by their visual qualities (light, palette, material), not by vague trend names or a competitor's name.
- Respect the brand profile: palette, photo style, banned visuals. Keep local context (people, food, setting) true to the target market.
- The prompts are a draft for the owner; the wording of the copy is the owner's decision.

## Prompt example (invented product)

Product: Lá Sớm ginger-honey tea, 20 sachets (fictional). Role: marketplace cover, 1:1.

Vietnamese (for review):

```text
Tạo ảnh bìa thương mại điện tử cho hộp trà gừng mật ong Lá Sớm (theo ảnh tham chiếu đính kèm), tỷ lệ 1:1. Hộp đặt chính diện, chiếm khoảng 70% khung hình, nền be nhạt chuyển sắc, bóng đổ mềm bên dưới. Ánh sáng khuếch tán mềm từ trên trái, tông ấm tự nhiên, ảnh sản phẩm chân thực, nét cao. Giữ nguyên hình dáng, màu sắc, nhãn và cấu trúc hộp như ảnh tham chiếu; không thiết kế lại, không đổi nhãn.
Nội dung chữ: “Trà gừng mật ong” (dòng chính, góc trên trái, chữ nâu đậm, căn trái) và “20 gói tiện dùng” (dòng phụ, nhỏ hơn). Toàn bộ chữ nằm trong 80% trung tâm, không che hộp.
Không thêm chữ nào ngoài nội dung trên; không sai chính tả hoặc dấu, không watermark, không nhãn giả, không hộp thừa hoặc méo.
```

English version (for the generator):

```text
Create a 1:1 marketplace cover for the Lá Sớm ginger-honey tea box (use the attached reference image). Box front-facing, about 70% of the frame, on a soft beige gradient, gentle shadow beneath. Soft diffused light from the upper left, warm natural tone, realistic product photography, high sharpness. Keep the exact shape, colour, label and box structure of the reference; do not redesign or relabel.
On-image text: "Trà gừng mật ong" (main line, top left, dark brown, left-aligned) and "20 gói tiện dùng" (smaller sub-line). Keep all text inside the central 80% and clear of the box.
No extra text beyond the above; no misspelling or wrong diacritics, no watermark, no fake label, no duplicate or distorted box.
```

## Generation step (only with a connected tool and explicit approval)

1. Confirm the tool, the number of images, the resolution and the quoted cost for this run; wait for a clear yes.
2. Generate the smallest set first (one or two candidates), not the full batch.
3. Review each result with the checklist; report failures plainly and propose a prompt repair.
4. Upscale only the chosen candidate, in a fidelity-preserving mode for products, packaging and labels; reject any result where the label, shape or colour changed.
5. Save outputs as new files with clear names (for example `01-cover`, `02-benefit`); never overwrite existing files.

## Output rules

- End with one concrete next step (for example: approve prompts 1 to 3, or send a better front photo).
- Label assumptions and placeholders. Treat every number here as a reference point and check it against the platform's current rules.
- Save as a NEW Google Doc or Slides if a connection exists, otherwise reply in the conversation. Never overwrite an existing file.
- Do not send, publish, upload to a shop, spend money or change anything outside the conversation without the user's go-ahead.
- Optional: offer a layout diagram through the `visual-thinking` skill if installed, otherwise a plain-text table.

## Quality bar

- The brief is complete or the gaps are listed; brand-profile limits are respected.
- Every image slot has a role, a mode, and exactly one Vietnamese prompt plus its English version.
- Product fidelity lock is present; no invented claim, price, certificate or review.
- Quoted copy has correct diacritics and fits the safe zone; the ratio matches the platform.
- Cost and generation are never assumed; the status line says "not generated" unless approved and done.
- The checklist in `references/brief-and-delivery.md` passed, or exceptions are stated.

## Files

- `references/brief-and-delivery.md`: normalised brief, delivery template, review checklist, prompt repair table.
- `references/visual-language.md`: photo styles, angles, compositions, lighting, seasonal and gift-set cues.
