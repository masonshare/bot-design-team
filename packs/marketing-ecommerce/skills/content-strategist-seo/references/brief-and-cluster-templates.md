# Templates: cluster map and content brief

All examples are invented. Fill the brackets; leave "user data needed" where figures are missing.

## Cluster map

Pillar: [title] | target query [query] | intent [type] | stage [stage] | angle [differentiator]

| Page | Target query | Intent | Stage | Format | Priority (H/M/L) | Links to | Volume / difficulty |
|---|---|---|---|---|---|---|---|
| [cluster 1] | [query] | [type] | [stage] | [format] | [H/M/L] | pillar, [sibling] | user data needed |

Link rules: each cluster page links to the pillar and 2 to 3 siblings; the pillar links to every cluster page; add one link from a high-traffic existing page to each new page.

Execution order: 1) pillar outline, 2) highest value and lowest competition, 3) the rest. State the reason for each.

## Content brief

```

Voice: [from brand profile or voice handoff, or "to be set"]

Target query: [query]

Length range: [read from competing pages; label as reference range]
Funnel stage: [awareness / consideration / decision]

  H3: [only if the section splits]

[what makes this worth publishing; if none, recommend not writing]

```

## Copywriter handoff block

Put this line on top of the brief: "Fixed: headings, direct-answer spec, terms, links. Free: voice, prose, examples, hooks."
